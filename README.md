# Moda Interact static website

This bundle contains a simple static company website for Moda Interact Ltd.

## Files

- `index.html`
- `privacy.html`
- `terms.html`
- `contact.html`
- `styles.css`
- `assets/moda-interact-logo.jpg`

## Before publishing

Search and replace these placeholders in all HTML files:

- `YOUR_COMPANY_NUMBER`
- `Office 20935 182-184 High Street North, London, E6 2JA`
- `contact@modainteract.com`
- `modainteract.com`

## Free deployment options

### Option 1: Cloudflare Pages
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Create a free Cloudflare account.
4. Go to **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
5. Select your repository and deploy.
6. Add your custom domain in the Pages project settings.

### Option 2: GitHub Pages
1. Create a public GitHub repository.
2. Upload these files.
3. In the repo, go to **Settings** → **Pages**.
4. Deploy from the main branch.
5. Add your custom domain under GitHub Pages settings.

## Notes
- The styling uses a green palette matched to the supplied Moda Interact logo.
